# Case de Negócio

## Projeto

Pipeline de Engenharia de Dados para Inteligência de Preços de Combustíveis

## Contexto

A AgroEnergy Analytics é uma empresa fictícia especializada em
inteligência de mercado para os setores de combustíveis e bioenergia.

A empresa necessita acompanhar a evolução dos preços de combustíveis
no Brasil e integrar diferentes fontes de dados para apoiar análises
de mercado e futuras aplicações de Machine Learning.

Atualmente, a obtenção e análise dessas informações é um processo
fragmentado, dificultando a atualização periódica, a rastreabilidade
dos dados e a manutenção de um histórico confiável.

## Problema

Construir uma plataforma de dados capaz de coletar periodicamente
informações provenientes de fontes públicas, preservar os dados
originais, realizar validações de qualidade, aplicar regras de negócio
e disponibilizar dados confiáveis para análises e modelos preditivos.

## Objetivo

Desenvolver um pipeline de Engenharia de Dados ponta a ponta,
contemplando ingestão, armazenamento, processamento, qualidade,
modelagem, observabilidade e disponibilização dos dados.

A solução utilizará arquitetura em nuvem e o Microsoft Fabric como
plataforma principal de processamento e análise.
